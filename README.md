# School Management System

A Java web application developed using Servlets, JSP, JDBC, and SQL following MVC architecture.

## Features
- Student registration and login
- Add, update, delete, and view student records
- JDBC-based database connectivity
- Session handling
- MVC architecture
- Deployed on Apache Tomcat

## Technologies Used
- Java
- Servlets & JSP
- JDBC
- PostgreSQL / MySQL
- Maven
- Apache Tomcat

## Project Structure
- Controller Layer: Servlets
- Service Layer: Business logic
- DAO Layer: Database operations
- View Layer: JSP pages

## How to Run the Project
1. Clone the repository
2. Import the project into Eclipse or IntelliJ
3. Configure database connection in DAO
4. Deploy the project on Apache Tomcat server
5. Access the application through browser
